# Data Availability Inventory

The manuscript's Data Availability Statement is implemented by the following repository
materials.

| Manuscript statement item | Repository location | Availability note |
|---|---|---|
| Per-source counts, versions, and licence terms | `dataset/roadrdd/SOURCES.md`, `dataset/roadrdd/sources.csv` | Public in this repository. |
| Source-group and split manifest | `dataset/roadrdd/split_manifest.csv`, `dataset/roadrdd/MANIFEST.sha256` | Generated by the reconstruction pipeline and included for auditability. |
| Byte-level audit and group-disjoint re-splitting | `src/tools/audit_dataset.py`, `src/tools/group_disjoint_resplit.py`, `dataset/roadrdd/audit/` | Public in this repository. |
| Model configurations and implementation | `src/ultralytics/cfg/models/rt-detr/`, `src/ultralytics/nn/extra_modules/` | Public in this repository. |
| Training, validation, inference, and profiling code | `src/train.py`, `src/val.py`, `src/detect.py`, `src/tools/profile_model.py` | Public in this repository. |
| Reproduction settings and profiler output | `configs/`, `docs/reproducibility.md`, `logs/profiler/` | Public in this repository. |
| RDD2022 images and labels | Official RDD2022 release | Not redistributed; see the official release cited in the manuscript. |
| In-domain derived images | Original sources listed in `SOURCES.md` | Not redistributed because source licences vary; reconstruct with the supplied pipeline. |

The repository does not redistribute third-party image archives or their derived image copies.
Users must obtain each source through its official route and comply with the source licence.

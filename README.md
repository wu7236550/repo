# A Lightweight RT-DETR for Road Crack and Pothole Detection

Code, reconstruction pipeline and evaluation scripts for the manuscript:

> **A Lightweight Real-Time Detection Transformer with Multi-Scale Partial
> Convolution and Context-Anchored Fusion for Road Crack and Pothole Detection**

The task is **two-class (`crack` = 0, `pothole` = 1) detection** on a
group-disjoint, 8,695-image benchmark built from public crack and pothole
sources, with a source-disjoint external test on the multi-national
**RDD2022** dataset.

This repository is organised as a **code + reproducible-pipeline** release: it
contains the model implementation, every ablation and control configuration,
the byte-level audit and group-disjoint re-splitting scripts, the source
manifest and the profiler logs. Following the licensing terms of the upstream
collections (some are non-commercial research only), bulk derived images are
not redistributed; they are reconstructed from the official sources with the
commands below.

## 2. Model

Three scenario-adapted modifications of RT-DETR-R18:

1. **MSPC** (Multi-Scale Partial Convolution) — lightweight backbone. A
   full-width 3×3 convolution is followed by channel splitting and by depthwise
   5×5 and 7×7 convolutions on progressively narrower slices (1/2 then 1/4),
   concatenated and fused by a 1×1 convolution inside a cross-stage-partial
   residual wrapper. Implemented as `MSPC` / `MSPConv` in
   `src/ultralytics/nn/extra_modules/block.py`.
2. **MCAF** (Multi-scale Context-Anchored Fusion) — replaces the cross-scale
   fusion blocks with a re-parameterised RepNCSPELAN4 topology paired with
   context anchor attention (CAA): a 7×7 average pool followed by serial
   horizontal (1×11) and vertical (11×1) depthwise convolutions (K = 11).
   Implemented as `MCAF` in `block.py` and `CAA` in
   `src/ultralytics/nn/extra_modules/attention.py`.
3. **LRPB-AIFI** (Learnable Relative Position Bias) — the fixed sinusoidal
   encoding in the attention-based intra-scale feature interaction is replaced
   by a small MLP that maps relative coordinate offsets (dx, dy) to per-head
   continuous biases (hidden = D/16; ≈ 0.8 k parameters). Bias tables are built
   at runtime for the actual feature-map size, so square and non-square inputs
   work without re-instantiation. Implemented as `LRPB_AIFI` /
   `LRPB_Attention` / `LRPB` in
   `src/ultralytics/nn/extra_modules/transformer.py`.

> LRPB receives only coordinate offsets and no image content, so it is a
> learnable, continuous parameterisation of relative position — **not** a
> content-dependent dynamic mechanism.

## 3. Datasets

### 3.1 In-domain benchmark (RoadRDD)

A detection derivative of public crack and pothole sources, resampled to
**416 × 416** with YOLO-normalized boxes. After the byte-level collapse and the
group-disjoint re-split:

| Split | Images |
|-------|-------:|
| train | 6,087 |
| val   | 869 |
| test  | 1,739 |
| **Total** | **8,695** |

16,797 boxes (8,439 crack / 8,358 pothole); 17 background-only frames. The
per-source breakdown, versions and license terms are in
[`dataset/roadrdd/SOURCES.md`](dataset/roadrdd/SOURCES.md).

### 3.2 External RDD2022 partition

A 10,000-image, four-country (China, Czech Republic, India, Japan) partition,
balanced per country (1,750 / 250 / 500 each; 7,000 / 1,000 / 2,000 in total),
sampled with a fixed released seed; 20,373 boxes (6,878 longitudinal, 4,142
transverse, 5,526 alligator, 3,827 pothole). The three crack categories are
merged to `crack`, potholes mapped to `pothole`, and the rare repair/blur
markings ignored. RDD2022 is publicly available at
<https://github.com/sekilab/RoadDamageDetector> and is not redistributed here.

## 4. Reconstruct the benchmark

```bash
# 1. Download each in-domain source from its official location (see SOURCES.md),
#    place the raw aggregate under raw/ (images/<split>/... + labels/<split>/...).

# 2. Byte-level audit / exact-copy collapse
python src/tools/audit_dataset.py --root raw --write

# 3. Deterministic group-disjoint re-split (fixed seed = 2024); plan, then apply
python src/tools/group_disjoint_resplit.py --in raw --out dataset/roadrdd
python src/tools/group_disjoint_resplit.py --in raw --out dataset/roadrdd --apply
```

The pipeline writes `MANIFEST.sha256`, `split_manifest.csv` and the reports in
`audit/`, and verifies that no byte-identical file and no source photograph is
shared across splits.

For the external partition, download RDD2022 from its official release and use
the mapping in Section 3.2.

## 5. Requirements and quick start

```bash
cd src
pip install -r requirements.txt

# train the proposed model (416x416, AdamW, 240 epochs; seeds 42/123/2024/7/31415)
python train.py --data ../configs/roadrdd.yaml --imgsz 416 --batch 16 --epochs 240 --seed 42

# train one of the eight factorial configurations
python train.py --cfg ultralytics/cfg/models/rt-detr/rtdetr-r18.yaml

# evaluate
python val.py --weights runs/roadrdd/train/<run>/weights/best.pt --split test --imgsz 416

# parameters / GFLOPs / throughput (logs to logs/profiler/)
python tools/profile_model.py
python tools/profile_model.py --device cuda     # reproduce the A6000 FPS

# unit tests for the resolution-adaptive relative position bias
pytest tests/test_lrpb_dynamic_size.py -v
```

The reported experiments used a single **NVIDIA RTX A6000 (48 GB)**, PyTorch 2.1
/ CUDA 11.8, AdamW (240 epochs, batch 16, lr 1e-4 → 1e-6 cosine, weight decay
1e-4, ~5-epoch warm-up, gradient clip 0.1, EMA 0.9999), loss gains
cls/L1/GIoU = 1/5/2.
